# 工作台设计与验收说明

本轮采用炭灰背景、暖橙色操作强调和独立状态色。深浅主题共用语义变量，中文内容使用本机字体回退，不依赖外部字体或图片。桌面以侧栏和顶栏组织操作，手机保留 Bot 上下文与导航入口。

布局参考用户指定仓库的 [开发者工具预设](https://github.com/Shart233/reactbits-demo/blob/main/lib/presets.ts)：借鉴终端与数据面板的工作台组织方式。未直接复制候选区块源码，也未引入其 Next.js、Three.js 或额外动效依赖。页面与布局独立实现，继续使用项目现有表单、弹窗、HeroUI 状态控件及提示。

总览只展示接口实际取得的连接、任务、实例和会话日志，不加入模拟趋势图或成功率。浏览器验收使用明确命名的“模拟 QQ”“模拟好友”夹具；这些测试数据不属于正式业务状态。

Bot 切换采用显式上下文与请求版本保护。发送对象变更时清空目标和正文，防止沿用上一 Bot；列表查询的迟到响应不能覆盖新对象。轮询不重新填充正在编辑的表单，隐藏标签页暂停周期请求，卸载后清理计时器。

页面切换只播放短入场过渡，避免退出阶段重新挂载新页面而丢失输入。支持减少动态效果、可见焦点、跳到主内容、弹窗焦点约束、Esc 关闭和焦点恢复。手机关闭侧栏时，导航项不可被键盘误选。

发送结果未决使用独立警告提示，保留编辑内容供核对，不显示成功，不触发自动重发。初始化、接口不可用、空列表和未连接状态保留明确入口。

回归脚本为 `tests/ui.spec.ts`，先构建前端，再执行 `npm run test:ui`。图像证据见 `output/migration-dashboard-dark.png`、`output/migration-dashboard-light.png`、`output/migration-dashboard-mobile.png` 和 `output/migration-schedules-dark.png`。完整实机操作和系统辅助功能工具审查仍属于后续验收。
